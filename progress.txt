### Key Learnings (Read This First!)

1. **Zod 4 API Change**: Use `error.issues` not `error.errors` for ZodError
2. **Type narrowing**: Always null-coalesce (`?? ''`) before assigning to non-nullable
3. **This codebase patterns**:
   - Types are in `src/types/`
   - Schemas use Zod in `src/next/publish/schema/`
   - PlaceholderKey type is defined in publish config
   - Council type is in `src/types/` or `src/lib/councils.ts`

### Common Fix Patterns

```typescript
// Zod error access

// NEW (working): error.issues

// Null to string
// OLD: const x: string = maybeNull;
// NEW: const x: string = maybeNull ?? '';

// Optional property access
// OLD: obj.prop.method()
// NEW: obj.prop?.method()
```
