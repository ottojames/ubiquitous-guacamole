### Key Learnings (Read This First!)

1. **Zod 4 API Change**: Use `error.issues` not `error.errors` for ZodError
2. **Type narrowing**: Always null-coalesce (`?? ''`) before assigning to non-nullable
3. **This codebase patterns**:
   - Types are in `src/types/`
   - Schemas use Zod in `src/next/publish/schema/`
   - PlaceholderKey type is defined in publish config
   - Council type is in `src/types/` or `src/lib/councils.ts`

### Common Fix Patterns

```typescript
// Zod error access
// OLD (broken): error.errors
// NEW (working): error.issues

// Null to string
// OLD: const x: string = maybeNull;
// NEW: const x: string = maybeNull ?? '';

// Optional property access
// OLD: obj.prop.method()
// NEW: obj.prop?.method()
```

## Iteration 32 - Research postcode → council lookup methods
**Status**: PASS
**Agent Flow**: Research (WebSearch, WebFetch)
**Files Changed**: PRD.md
**What Happened**: Researched and documented comprehensive postcode → council lookup methods:

**Options Evaluated:**
1. **Postcodes.io** (Recommended): Free, no auth, no rate limits, returns admin_district + admin_county + GSS codes
2. **GOV.UK Local Authorities API**: Free but undocumented, unversioned, rate limited, "may change without notice"
3. **MapIt**: £22/mo (free for non-profit), requires API key, tiered rate limits
4. **ONS NSPL Dataset**: Free download, offline use, ~300MB quarterly CSV

**Key Findings:**
- Postcodes.io is backed by ONS NSPL data, updated quarterly
- Two-tier areas return `admin_district` (e.g., "Guildford") + `admin_county` (e.g., "Surrey")
- Unitary areas return `admin_district` only, `admin_county` is null
- ~1.2% of UK addresses (387,000) are in different LA than postcode centroid - unavoidable limitation

- Phase 1 (MVP): Use Postcodes.io API directly
