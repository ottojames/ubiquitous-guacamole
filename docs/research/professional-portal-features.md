# Professional Portal for Licensing Consultants: Feature Requirements

*Research conducted from perspective of a licensing consultant handling 50+ applications annually*

## Executive Summary

A professional portal must solve core pain points of manual tracking, deadline management, and client communication while providing ROI through time savings and error reduction.

## 1. Dashboard - Critical Metrics

### Primary Views
- **Applications by Status**: Pipeline showing In Progress, Pending, Awaiting Publication, Published
- **Deadline Urgency**: Color-coded alerts (7 days, 14 days, 30+ days)
- **Revenue Pipeline**: Current month invoiced vs pending, average case value
- **Workload Capacity**: Applications per week vs historical average

### Weekly Consultant View
- This Week's Actions: What specifically needs doing today/tomorrow
- Client Health: Outstanding payments, inactive clients
- Performance Metrics: Average time per application type

### Monthly Business Intelligence
- Profitability by Application Type
- Geographic Patterns: Council speed, newspaper pricing by region
- Seasonal Trends: Application peaks, renewal cycles

## 2. Workflow Stages

### Stage 1: Intake & Assessment
- Digital intake form (embeddable in client websites)
- Automatic eligibility checker
- Cost estimation with breakdown
- Document checklist by application type

### Stage 2: Newspaper Selection
- **Postcode-driven recommendations** with circulation data
- Cost comparison matrix
- Council preference tracking
- Historical performance data (which newspapers are fastest)

### Stage 3: Notice Drafting
- Template library by license type
- Mail-merge from application data
- Version control with tracked changes
- Client approval workflow
- **Legal compliance checker**

### Stage 4: Submission & Tracking
- **Integrated Adfast submission**
- Proof of submission auto-filed
- Publication tracking with expected dates
- Issue resolution workflow

### Stage 5: Proof & Delivery
- **Automated proof collection** from Mediafairy
- Client notification with white-labeled reports
- Final invoice generation
- Feedback collection

## 3. Automation Opportunities

### High-Impact
- Deadline calculations (council times + newspaper lead times)
- Template population from intake data
- Council-specific formatting
- Invoice generation with automatic markup
- Follow-up sequences

### Smart Suggestions
- Newspaper optimization (cheaper alternatives with same coverage)
- Batch processing for similar applications
- Renewal reminders for expiring licenses
- Cross-sell opportunities

## 4. Client Management

### Client Portal
- Real-time application status
- Document upload
- Invoice history
- **White-label branding** (consultant's brand, not Civic Notices)

### Billing
- Flexible models: Fixed fee, time-based, markup on costs
- Automatic invoicing on milestones
- Payment tracking with aging reports
- Profitability analysis by client

## Value Propositions

1. **Professional Client Experience**: Branded portal, real-time updates
2. **Proactive Problem Prevention**: Catches issues before they become problems
3. **Scalability Without Chaos**: Handle 100+ applications as easily as 10
4. **Data-Driven Decisions**: Pricing based on actual data, not guesswork
5. **Regulatory Compliance**: Built-in legal checking, audit trails
