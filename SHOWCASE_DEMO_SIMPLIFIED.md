```sql
CREATE TABLE IF NOT EXISTS public.email_subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

  -- Subscriber Info
  email TEXT NOT NULL,
  postcode TEXT NOT NULL,

  -- Preferences
  radius_km INTEGER NOT NULL DEFAULT 5 CHECK (radius_km BETWEEN 1 AND 50),
  notice_types TEXT[] NOT NULL DEFAULT ARRAY['all'],

  -- Verification
  verified BOOLEAN NOT NULL DEFAULT FALSE,
  verification_token TEXT,
  verification_expires_at TIMESTAMPTZ,

  -- Status
  status TEXT NOT NULL DEFAULT 'pending'
    CHECK (status IN ('pending', 'active', 'paused', 'unsubscribed')),

  -- Coordinates (geocoded from postcode)
  latitude DECIMAL(10, 7),
  longitude DECIMAL(10, 7),

  -- Metadata
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  last_email_sent_at TIMESTAMPTZ,

  CONSTRAINT unique_email UNIQUE (email),
  CONSTRAINT valid_email CHECK (email ~* '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$')
);

CREATE INDEX idx_email_subs_status ON email_subscriptions(status);
CREATE INDEX idx_email_subs_verified ON email_subscriptions(verified);
CREATE INDEX idx_email_subs_location ON email_subscriptions(latitude, longitude);
```

### API Endpoints Summary

**Notice Search**: `GET /api/notices/search`
- Query params: `q`, `postcode`, `council`, `type`, `status`, `start`, `end`, `traffic_area`, `radius_km`, `lat`, `lng`, `bbox`, `sort`, `limit`
- Returns: Array of notices with distance (if postcode), total count, pagination
- Geospatial queries use PostGIS + Haversine distance
- Auto-geocodes postcodes via postcodes.io

**Notice Detail**: `GET /api/notices/:id`
- Returns: Full notice details + council data + coordinates

**Representation Submit**: `POST /api/representations`
- Payload: `noticeId`, `submitterName`, `submitterEmail`, `submitterAddress`, `type`, `licensingObjectives`, `content`
- Validation: Checks deadline hasn't passed, 10-10,000 char limit
- Returns: Reference number (REP-XXXXXX), opens email client

**Bbox Search**: Uses PostGIS `ST_MakeEnvelope` and `ST_Within` for map viewport queries

**Radius Search**: Uses PostGIS `ST_DWithin` for proximity searches
