1. Select upload method: "Structured template" OR "Upload via File"
2. ✅ Upload signed Blue Notice PDF
3. ✅ OCR extracts text content (not structured fields)
4. ✅ User manually fills in required fields:
   - Applicant name
   - Premises address (with postcode)
   - Consultation deadline
5. Platform validates fields
6. Preview notice (combining extracted text + validated fields)
