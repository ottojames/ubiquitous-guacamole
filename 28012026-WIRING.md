## Executive Summary

This audit reveals **multiple critical wiring failures** in the council portal that explain why:
- Analytics shows ZERO total notices
- Audit log remains EMPTY
- Comments on representations FAIL

The root causes are:
1. **CRITICAL BUG**: `server/routes/council.ts` uses undefined `supabase` variable
2. **DATA FLOW GAPS**: Components query correct tables but API routes are broken
3. **AUDIT TRIGGERS**: Exist but are not firing due to missing department_id on notices

### FIX C3: audit_logs department_id NULL (CRITICAL)

**File:** `/Users/ottoclarke/projects/Ralph's Civic Notices/supabase/migrations/` (new migration)

**Problem:** `audit_notice_changes()` trigger doesn't capture `department_id` when notice lacks it.

**Fix:** Update trigger to look up department from notice context:

```sql
-- New migration: 20260128100001_fix_audit_department_id.sql

CREATE OR REPLACE FUNCTION audit_notice_changes()
RETURNS TRIGGER AS $$
DECLARE
  dept_id uuid;
BEGIN
  -- Get department_id from the notice itself or resolve from organization
  dept_id := COALESCE(
    NEW.department_id,
    OLD.department_id,
    (SELECT d.id FROM departments d WHERE d.organization_id = COALESCE(NEW.organization_id, OLD.organization_id) LIMIT 1)
  );

  INSERT INTO audit_logs (
    department_id,
    organization_id,
    user_id,
    action,
    action_category,
    resource_type,
    resource_id,
    old_values,
    new_values,
    severity
  ) VALUES (
    dept_id,
    COALESCE(NEW.organization_id, OLD.organization_id),
    auth.uid(),
    TG_OP,
    'notice',
    'notice',
    COALESCE(NEW.id, OLD.id),
    CASE WHEN TG_OP = 'DELETE' OR TG_OP = 'UPDATE' THEN to_jsonb(OLD) ELSE NULL END,
    CASE WHEN TG_OP = 'INSERT' OR TG_OP = 'UPDATE' THEN to_jsonb(NEW) ELSE NULL END,
    'info'
  );

  RETURN COALESCE(NEW, OLD);
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```

CREATE TABLE representation_reads (

  user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE,
  read_at timestamp with time zone DEFAULT now(),
  PRIMARY KEY (representation_id, user_id)
);
