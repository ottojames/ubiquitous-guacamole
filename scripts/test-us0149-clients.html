US-0149: Client Management - Browser Test

Test Environment

Frontend: http://localhost:5173

API Server: http://localhost:5174

Demo Mode: VITE_DEMO_MODE=true

Acceptance Criteria to Test:

  1. ✅ Clients page is in firm portal navigation
  2. ✅ List shows all firm clients with: name, contact, number of active notices, last notice date
  3. ✅ "Add Client" button creates new client profile
  4. ✅ Client form has: name, contact person, email, phone, address fields
  5. ✅ Click client to see: all their notices, representations received, history
  6. ✅ Can edit client details
  7. ✅ Publish notice for client appears in client notices list

Step 1: Navigate to Firm Portal

Open: http://localhost:5173/f/wilson-partners/clients

Expected: Clients page loads with list of clients

Step 2: Verify Client List Display

Check that the client list shows:

  • Client name
  • Contact details (name, email, phone)
  • Number of notices badge
  • Date client was added
  • Active/Inactive status

Step 3: Test Add Client

  1. Click "Add Client" button
  2. Fill in form:
    • Name: "The Red Lion Pub"
    • Contact: "John Smith"
    • Email: "john@redlion.com"
    • Phone: "020 7123 4567"
    • Address: "45 High Street, London, SW1A 1AA"
  3. Click "Add Client"
  4. Verify: Client appears in list

Step 4: Test Edit Client

  1. Click "Edit" button on a client
  2. Change contact name
  3. Click "Update Client"
  4. Verify: Changes reflected in list

Step 5: Test Quick Publish

  1. Click "Quick Publish" button on a client
  2. Should navigate to: /f/wilson-partners/publish/step-1?client=[slug]
  3. Verify client parameter is in URL

Step 6: Test View Notices

  1. Click "View Notices" link on a client
  2. Should navigate to: /f/wilson-partners/notices?client=[slug]
  3. Verify notices are filtered by client

Step 7: Test Search Functionality

  1. Type "Red Lion" in search box
  2. Verify: Only matching clients show
  3. Clear search
  4. Verify: All clients show again

Manual Testing Instructions

  1. ✅ Page loads at /f/wilson-partners/clients
  2. ✅ Mock clients display (The Red Lion Pub, Westminster Entertainment, Soho Bars)
  3. ✅ Add Client modal opens and has all required fields
  4. ✅ Edit Client modal pre-populates with existing data
  5. ✅ Quick Publish navigates to wizard with client parameter
  6. ✅ View Notices navigates to notices page with client filter
  7. ✅ Search filters clients correctly
